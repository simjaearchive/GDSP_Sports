# 2026학년도 강동송파 교육장배 올스타 학교스포츠클럽대회 · 일정/결과 공유 앱

웹브라우저만 있으면 누구나 **농구 / 3X3 농구 / 배구 / 배드민턴 / 피구** 5개 종목의
경기 일정과 결과를 볼 수 있고, **비밀번호를 아는 관리자**는 공지사항과 경기 결과를 웹페이지에서 바로 입력할 수 있습니다.
(경기 일정 자체는 관리자 탭에서 등록하지 않고, 구글 스프레드시트를 참고해 `matches` 데이터로 일괄 등록합니다.)

## 2. 기능

* **첫 화면** : 농구·3X3 농구·배구·배드민턴·피구 5개 종목 카드 선택
* **종목별 화면** : 날짜별 경기 목록, 시간·장소·구분(부문)·라운드, 점수/결과
  * **농구·3X3 농구**는 그 아래에 **조별예선 / 본선 토너먼트** 탭이 있고, 그 아래에 또 세부 구분 탭이 있습니다.
    * 농구: 여중 1,2학년 · 남중 1,2학년 · 여고 1,2학년 · 남고 1,2학년
    * 3X3 농구: 여초 5,6학년 · 남초 5,6학년 · 여중 3학년 · 남중 3학년 · 여고 3학년 · 남고 3학년
    * **조별예선**을 선택하면 그 아래에 **조 탭**이 한 번 더 나오고, 그 조의 경기가 **일시 · 장소 · 결과** 3칸짜리 표로 한눈에 보입니다. 결과 칸(팀명·점수)은 크고 굵게, 일시·장소는 작게 표시해서 결과가 가장 눈에 띄도록 했습니다.
    * **본선 토너먼트**를 선택하면 **8강 토너먼트 대진표**가 나옵니다 — 8강(4경기) → 4강(2경기) → 결승(1경기) 순서로 쌓여 있고, 아직 등록 안 된 자리는 "미정 vs 미정"으로 표시돼서 대진표 모양 자체는 항상 보여요. 각 경기 칸에는 날짜·시간·장소·학교명·결과가 모두 표시됩니다. 예전에 있던 날짜별 "전체" 필터는 대진표로 바뀌면서 없어졌습니다. 폭이 좁은 화면에서도 가로 스크롤 없이 한 줄씩 보이도록 세로로 쌓는 방식이라 휴대폰 세로 화면에서도 잘 보입니다.
    * 구분(부문)마다 조 개수가 다릅니다 — 지정 안 된 구분은 기본값 A~F조입니다.
      * 농구: 여중 1,2학년 A~D조 · 여고 1,2학년 A~B조 · (남중·남고는 기본 A~F조)
      * 3X3 농구: 여초 5,6학년 A~B조 · 남초 5,6학년 A~C조 · 여고 3학년 A~B조 · (나머지는 기본 A~F조)
      * `index.html`의 **`⑥ 조별예선 안에서 나뉘는 조`** 부분(`POOLS_BY_DIVISION`)에서 언제든 조 개수를 조정할 수 있습니다.
  * **배구**는 **조별예선 / 본선 토너먼트 / 풀리그 / 🔍 검색** 탭으로 구성됩니다 (엑셀 `2026 강동송파 올스타 교육장배 학교스포츠클럽대회 일정표(배구).xlsx` 기준 51경기가 처음 접속 시 자동 등록됨).
    * 조별예선·본선 토너먼트: 남중저학년 · 여중저학년 · 여고 (A·B조 → 4강 → 결승)
    * 본선 토너먼트 자동 채우기: 조별예선이 모두 끝나면 "여고A조 1위팀" 자리에 해당 학교명이 자동 표시되고(조 순위 기준: 승수 → 점수 득실율(득점÷실점) → 세트 득실 → 승자승. 기권·몰수 경기는 관리자 탭의 "기권·몰수" 선택으로 입력하며, 승은 인정하되 점수율 환산에는 넣지 않음), 4강이 끝나면 결승의 "1경기 승팀" 자리에 이긴 학교가 표시됩니다.
    * 풀리그: 남중고학년 · 여중고학년 · 남고
    * 관리자 탭의 결과 입력도 같은 단계 → 종별 → 조 순서로 경기를 고른 뒤 세트 점수를 입력합니다.
  * 처음 접속하면 농구 · 조별예선 · 남중 1,2학년의 A~F조에 **"OO중학교"라는 맛보기 샘플 경기**가 하나씩 채워져 있습니다 — 표 디자인을 먼저 확인해보시라고 넣어둔 더미 데이터이니, 관리자 탭에서 실제 학교명·날짜·장소로 고쳐 쓰거나 삭제하면 됩니다. (한 번만 자동으로 채워지고, 이후에는 다시 채워지지 않습니다.)
  * 모든 종목 화면에는 **🔍 검색** 탭이 있어서, 학교 이름을 입력하면 날짜·단계에 상관없이 그 학교가 나오는 경기를 전부 모아서 보여줍니다.
* **관리자 탭** : **① 관리할 종목을 먼저 선택 → ② 그 종목의 관리자 코드 입력**(지금은 5개 종목 모두 `1379`로 통일. 종목마다 다른 코드를 쓰려면 `index.html`의 `ADMIN_PW_BY_SPORT` 값을 각각 바꾸면 됩니다) 후
  * **경기 결과 입력** — 종목별로 입력 방식이 다르며, 입력한 결과는 "경기 일정·결과" 화면에 그대로 반영됩니다. (경기 등록·수정·삭제 기능은 없습니다.)
    * **배구**: 1~3세트 각 팀 점수 입력 → 세트별로 이긴 팀 1점·진 팀 0점 자동 부여 → 최종 세트 점수 자동 표시(2세트 선승 시 승자 확정)
    * **배드민턴**: 1~3세트 각 팀 점수 입력 → 총 득점(1~3세트 합산)이 높은 팀 승리, 총 득점이 같으면 세트 득실차, 그것도 같으면 점수 득실차로 판단(1~3세트를 모두 입력하면 결과 확정)
* **저장 완료 안내** : 관리자 탭에서 공지·경기 결과를 저장하면 화면 하단에 "✅ 저장 완료"가 표시됩니다 (저장 실패 시에는 오류 경고창)
    * **피구**: 1~2세트 각 팀 승/무/패 선택 → 승점제(승 3점 · 무 1점 · 패 0점) 자동 합산, 내야 총득점 별도 입력. 두 세트를 모두 입력하면 승점 비교로 승/무/패 확정
    * **농구·3X3 농구**: 점수(자유 입력)와 승자 선택
  * **공지사항 입력** — **대회 전체 공지사항**(모든 종목 화면 상단에 공통 표시)과 **종목별 공지사항**(선택한 종목 화면에만 표시)을 따로 입력·저장·삭제할 수 있습니다.
  * 종목 하나를 인증(로그인)하면 그 종목만 잠금이 풀립니다. 다른 종목을 관리하려면 "← 종목 선택"으로 돌아가 그 종목 코드를 따로 입력해야 합니다.
* 결과·경기 등록/수정 내용은 **모든 접속자 화면에 새로고침 없이 자동 반영** (Firebase 연결 시)

## STEP 3. Firebase 실시간 데이터베이스 연결 (선택)

### 3-1. 프로젝트 만들기
[https://console.firebase.google.com](https://console.firebase.google.com) → **프로젝트 만들기** (예: `kdsp-allstar-2026`) → 애널리틱스는 사용 안 함

### 3-2. Realtime Database 만들기
왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기** → 위치는 **싱가포르(asia-southeast1)** 권장 → **테스트 모드로 시작**

### 3-3. 보안 규칙 설정
**규칙(Rules)** 탭에 아래 내용을 붙여넣고 **게시**.
(이 앱은 관리자가 경기 자체를 등록/수정/삭제하므로, 비밀번호는 화면 잠금으로만 확인하고
데이터베이스 규칙은 단순하게 둡니다 — 링크를 아는 사람만 관리자 탭에 들어갈 수 있다는 전제입니다.)

```json
{
  "rules": {
    "matches": { ".read": true, ".write": true },
    "noticeGlobal": { ".read": true, ".write": true },
    "noticeBySport": { ".read": true, ".write": true }
  }
}
```

> 대회가 끝난 뒤에는 `.write` 값을 모두 `false` 로 바꿔 결과가 더는 바뀌지 않도록 잠그는 것을 권장합니다.

### 3-4. 웹 앱 등록 후 설정값 복사
**프로젝트 설정(톱니바퀴) → 내 앱 → 웹 아이콘 `</>`** → 앱 등록(호스팅 체크 불필요) → 아래 값 복사

```js
const firebaseConfig = {
  apiKey: "AIza............",
  authDomain: "kdsp-allstar-2026.firebaseapp.com",
  databaseURL: "https://kdsp-allstar-2026-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "kdsp-allstar-2026",
  storageBucket: "kdsp-allstar-2026.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef......"
};
```

> `databaseURL` 이 안 보이면 3-2(Realtime Database 만들기)를 먼저 하세요.

### 3-5. index.html에 붙여넣기
GitHub에서 `index.html` 연필(Edit) 아이콘 → **`① Firebase 설정`** 부분의 `firebaseConfig` 를 위 값으로 교체 → **Commit changes**
1~2분 뒤 Pages 주소를 새로고침하면 상단이 **"실시간 연결됨"** 으로 바뀝니다.

## STEP 4. 사용 방법

### 일반 사용자
* Pages 주소를 열고 종목 카드를 선택하면 해당 종목 일정/결과가 보입니다. 로그인 불필요.
* 결과가 입력되는 즉시 화면이 자동으로 바뀝니다 (실시간 모드일 때).

### 관리자
1. **관리자** 탭 → 관리할 **종목 카드를 선택** (🏀🏸🏐 등)
2. 그 종목의 관리자 코드 **`1379`** 입력 → 확인 (종목마다 따로 인증합니다)
3. 목록에서 해당 경기를 찾아 종목별 결과 칸(세트 점수 등)을 입력하면 아래에 자동 계산 결과가 미리 보이고, **결과 저장**을 누르면 모든 화면에 반영됩니다. (농구·3X3 농구는 단계/구분/조 탭으로 경기를 찾습니다)
4. 잘못 입력했다면 **결과 초기화**로 되돌릴 수 있습니다.
5. **대회 전체 공지사항** 칸에 적고 **전체 공지 저장**을 누르면 모든 종목 화면 상단에 표시됩니다.
6. 특정 종목에만 보여줄 안내라면 그 아래 **종목별 공지사항** 칸에 적고 **종목 공지 저장**을 누르세요. 해당 종목 화면에만 표시됩니다.
7. 다른 종목도 관리하려면 **"← 종목 선택"**으로 돌아가 그 종목을 고르고 코드를 입력하세요.

## 보안 안내
* 관리자 코드(`1379`)는 브라우저에서 동작하는 **간이 잠금**입니다. 개발자도구로 우회 가능하므로,
  링크가 외부에 널리 퍼지는 상황이라면 결과가 조작될 가능성이 있습니다.
* 대회 기간 중에는 큰 문제가 없지만, 더 엄격하게 하려면 대회 종료 후 Firebase 규칙의 `.write` 를 `false` 로 바꾸세요.
* 개인정보는 저장되지 않으며, 팀명·일정·점수 등 대회 진행 정보만 저장됩니다.

## 관리자 코드 변경 (종목별로 다르게 설정 가능)
`index.html` 안의 **`② 관리자 비밀번호`** 부분을 보면 이렇게 되어 있습니다.

```js
const ADMIN_PW_BY_SPORT = {
  basketball: "1379",
  three:      "1379",
  volleyball: "1379",
  badminton:  "1379",
  dodgeball:  "1379"
};
```

지금은 5개 종목 모두 `1379`로 통일되어 있습니다. 종목마다 다른 코드를 쓰고 싶으면 해당 줄의 값만 원하는 코드로 바꾼 뒤 저장하면 됩니다. (예: `basketball: "0601",`)

## 문제 해결 (FAQ)
**Q. 상단이 계속 "이 브라우저 저장 모드"예요.**
→ STEP 3의 `firebaseConfig` 값이 비어 있습니다. `databaseURL` 이 채워졌는지 확인하세요.

**Q. 결과 저장 시 "저장 실패 / permission denied" 경고가 떠요.**
→ Realtime Database **규칙(Rules)** 을 3-3처럼 게시했는지, **게시** 버튼을 눌렀는지 확인하세요.

**Q. 다른 사람 화면에 결과가 안 보여요.**
→ 상단 표시가 "실시간 연결됨"인지 확인하세요. 로컬 모드에서는 각자 브라우저에만 저장됩니다.

**Q. GitHub Pages 주소가 404예요.**
→ 1~2분 기다렸다가 새로고침. Settings → Pages에서 Branch가 `main`인지, 저장소 이름이 `2026-` 인지 확인하세요.
